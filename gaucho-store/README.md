# Querência Gaúcha: vitrine com vendas pelo WhatsApp

Abra `index.html` no navegador (a pasta `img/` precisa ficar ao lado).

## Trocar o número do WhatsApp da loja
No final do `index.html`, procure por `CONFIGURE AQUI`:

```js
var WHATS='5551999990000',FONE='(51) 99999-0000';
```

- `WHATS`: só números, com `55` + DDD + número (usado nos links `wa.me`).
- `FONE`: como o número aparece escrito no site.

Todos os botões de compra abrem o WhatsApp com a mensagem pronta (produto e preço).
O coração salva itens numa lista e o botão verde do topo envia a lista inteira em uma mensagem.
